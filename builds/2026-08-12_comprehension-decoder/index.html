Java makes you write a loop outside-in: declare the result, open the loop,
    maybe an if, then finally the thing you keep. Python lets you write it
    the way you actually say it — the answer first:

    
[ what I keep  for each x in the source  if it passes the test ]

    

      green = the expression that lands in the new list
      blue = your old for header
      amber = your old if, optional
    

    
Read it left-to-right as a sentence: “keep x-squared, for each x in numbers,
    if x is even.” Same three parts as your loop — just reordered so the important bit (the answer)
    comes first. Swap [ ] for { } and you get a set; add a
    key: value and you get a dict. That's the whole language feature.
