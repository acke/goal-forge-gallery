What this is: a real IEEE 754 binary64 decoder. The "exact" value is computed with BigInt arithmetic — a double is always an integer times a power of two, and any such number has a terminating decimal, so the long tail you see is the true, complete value, not an approximation. What it isn't: it doesn't cover 32-bit floats or decimal128; and the "you typed" line shows how JavaScript parsed your text, which is itself already rounded to the nearest double — same rounding Java and Python do.

The one thing to take to work: floats aren't fuzzy, they're a grid that gets coarser as numbers grow. Past 2⁵³ the grid is wider than 1, so integers start skipping. Never == two floats; compare within a tolerance. — Natt 🌙
